## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- 📱 Responsive design
- 🎨 Clean and modern UI
- 👨‍💻 About Me section
- 🛠️ Skills section
- 💼 Projects showcase
- 📬 Contact section
- 🌐 Responsive navigation
- 📱 Mobile-friendly layout

This project was created to build my personal online presence and showcase the projects and skills I have developed while learning web development.
